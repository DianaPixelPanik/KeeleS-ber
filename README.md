# KeeleSõber iOS App

SwiftUI-прототип приложения для разговорной практики эстонского языка с режимами преподавателя, пошаговым уроком и базовой системой XP.

## Что реализовано

- Выбор стиля обучения: Friendly / Strict / Savage.
- Структура урока: слово → распознавание → мини-диалог → «скажи вслух» → оценка → спонтанный вопрос.
- Блок оценки в требуемом формате.
- Начальная логика XP и серия ответов.
- Загрузка текста из PDF, добавленных в Bundle приложения.

## Как подключить PDF-материалы

1. Добавьте один или несколько `.pdf` файлов в target приложения в Xcode.
2. При запуске приложение автоматически прочитает их через `PDFKit`.
3. Фрагменты будут выводиться в блоке «Материал из PDF».
